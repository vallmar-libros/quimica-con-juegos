# Soluciones · Capítulo 5. Ajustar ecuaciones (4.º)

Mírala después de comprobar, no antes. Cada solución la calcula un programa con cuentas exactas: ajuste con fracciones, masas desde la tabla y nombres con reglas.

## Q-05-01 · Ejemplo resuelto: el agua

(1) Sin coeficientes: izquierda H 2, O 2; derecha H 2, O 1. (2) Coeficientes 2, 1, 2: 2 H₂ + O₂ → 2 H₂O. (3) Comprobación: izquierda H 4, O 2; derecha H 4, O 2. Ajustada. Respuesta: 2 H₂ + O₂ → 2 H₂O (coeficientes 2, 1, 2).

## Q-05-02 · Síntesis

(1) Sin coeficientes: izquierda Fe 1, O 2; derecha Fe 2, O 3. (2) Coeficientes 4, 3, 2: 4 Fe + 3 O₂ → 2 Fe₂O₃. (3) Comprobación: izquierda Fe 4, O 6; derecha Fe 4, O 6. Ajustada. Respuesta: 4 Fe + 3 O₂ → 2 Fe₂O₃ (coeficientes 4, 3, 2).

## Q-05-03 · Combustiones

(1) Sin coeficientes: izquierda C 4, H 10, O 2; derecha C 1, H 2, O 3. (2) Coeficientes 2, 13, 8, 10: 2 C₄H₁₀ + 13 O₂ → 8 CO₂ + 10 H₂O. (3) Comprobación: izquierda C 8, H 20, O 26; derecha C 8, H 20, O 26. Ajustada. Respuesta: 2 C₄H₁₀ + 13 O₂ → 8 CO₂ + 10 H₂O (coeficientes 2, 13, 8, 10).

## Q-05-04 · Neutralizaciones

(1) Sin coeficientes: izquierda H 3, N 1, O 5, Mg 1; derecha H 2, N 2, O 7, Mg 1. (2) Coeficientes 2, 1, 1, 2: 2 HNO₃ + Mg(OH)₂ → Mg(NO₃)₂ + 2 H₂O. (3) Comprobación: izquierda H 4, N 2, O 8, Mg 1; derecha H 4, N 2, O 8, Mg 1. Ajustada. Respuesta: 2 HNO₃ + Mg(OH)₂ → Mg(NO₃)₂ + 2 H₂O (coeficientes 2, 1, 1, 2).

**El error del chat imaginario.** Paso 2: con esos coeficientes no cuadra H y O: izquierda H 4, N 2, O 8, Mg 1 y derecha H 6, N 2, O 9, Mg 1. Bien hecho: Coeficientes 2, 1, 1, 2: 2 HNO₃ + Mg(OH)₂ → Mg(NO₃)₂ + 2 H₂O. La respuesta correcta es 2 HNO₃ + Mg(OH)₂ → Mg(NO₃)₂ + 2 H₂O (coeficientes 2, 1, 1, 2).

## Q-05-05 · Con iones: cuadra también la carga

(1) Sin coeficientes: izquierda Cu 1, Ag 1; derecha Cu 1, Ag 1; carga +1 y +2. (2) Coeficientes 1, 2, 1, 2: Cu + 2 Ag⁺ → Cu²⁺ + 2 Ag. (3) Comprobación: izquierda Cu 1, Ag 2; derecha Cu 1, Ag 2; carga +2 a cada lado. Ajustada. Respuesta: Cu + 2 Ag⁺ → Cu²⁺ + 2 Ag (coeficientes 1, 2, 1, 2).

## Q-05-06 · Descomposiciones

(1) Sin coeficientes: izquierda Na 1, H 1, C 1, O 3; derecha Na 2, H 2, C 2, O 6. (2) Coeficientes 2, 1, 1, 1: 2 NaHCO₃ → Na₂CO₃ + H₂O + CO₂. (3) Comprobación: izquierda Na 2, H 2, C 2, O 6; derecha Na 2, H 2, C 2, O 6. Ajustada. Respuesta: 2 NaHCO₃ → Na₂CO₃ + H₂O + CO₂ (coeficientes 2, 1, 1, 1).

## Q-05-07 · Iones sin ayuda

(1) Sin coeficientes: izquierda Al 1, O 1, H 1; derecha Al 1, O 3, H 3; carga +2 y 0. (2) Coeficientes 1, 3, 1: Al³⁺ + 3 OH⁻ → Al(OH)₃. (3) Comprobación: izquierda Al 1, O 3, H 3; derecha Al 1, O 3, H 3; carga 0 a cada lado. Ajustada. Respuesta: Al³⁺ + 3 OH⁻ → Al(OH)₃ (coeficientes 1, 3, 1).

## Q-05-08 · Repaso: ¿está ajustada?

(1) 3 Mg + O₂ → 2 MgO: izquierda Mg 3, O 2; derecha Mg 2, O 2. No ajustada: no cuadra Mg. (2) 5 Al + 3 O₂ → 2 Al₂O₃: izquierda Al 5, O 6; derecha Al 4, O 6. No ajustada: no cuadra Al. (3) 2 C₂H₆ + 7 O₂ → 4 CO₂ + 6 H₂O: izquierda C 4, H 12, O 14; derecha C 4, H 12, O 14. Ajustada. (4) 4 NH₃ + 5 O₂ → 5 NO + 6 H₂O: izquierda N 4, H 12, O 10; derecha N 5, H 12, O 11. No ajustada: no cuadra N y O. Respuesta: a) no; b) no; c) sí; d) no.
